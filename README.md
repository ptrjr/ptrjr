# Olá, sou Mauricio Petri Junior

Sou estudante de Engenharia de Software na UNIASSELVI e curso Desenvolvimento Back-end no SENAI/SCTEC.

Meu foco atual é desenvolvimento back-end com Node.js, TypeScript e bancos de dados. Desenvolvo projetos acadêmicos e soluções baseadas em necessidades que identifico na minha rotina profissional.

Também utilizo desenvolvimento assistido por IA, envolvendo detalhamento de requisitos, refinamento de prompts, validação manual de fluxos e identificação de bugs.

## Projetos em destaque

- **[MEDCLINIC API](https://github.com/ptrjr/medclinic-api)** — projeto acadêmico em desenvolvimento, com autenticação JWT, controle de acesso para administradores e atendentes, Express, TypeORM e PostgreSQL.
- **[BookStore Manager CLI](https://github.com/ptrjr/bookstore-manager-cli)** — aplicação de terminal para gerenciamento de livros, clientes e empréstimos, utilizando Node.js, TypeScript e PostgreSQL.
- **[Almoxarifado Dashboard](https://github.com/ptrjr/almoxarifado-dashboard)** — projeto de controle de estoque com Java, Spring Boot e React.
- **LJ Core** — sistema interno em desenvolvimento para gestão operacional e administrativa, incluindo controle de ponto. Repositório privado; demonstração disponível mediante solicitação.

## Tecnologias que utilizo nos projetos

Node.js · TypeScript · Express · SQL · PostgreSQL · SQLite · TypeORM · Git
